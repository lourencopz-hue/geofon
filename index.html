Como usar o editor

Salvar grava direto no app — DMC já carregado só pede uma confirmação simples; polígono novo/importado (sem vínculo ainda) pergunta cidade e DMC (ou nome de um DMC novo) antes de gravar. Cada polígono sempre volta pro seu DMC certo, mesmo com vários na tela ao mesmo tempo. Use as ferramentas de desenho no canto do mapa (polígono, editar vértice, arrastar, excluir). Clique num polígono carregado pra selecioná-lo (fica vermelho) e baixar só ele. Com a edição de vértice ativa, clique com o botão direito num vértice pra apagar só ele (clique normal move o ponto). Deu ruim? O botão "Desfazer" volta o último passo. Verificar sobreposição compara os polígonos deste editor contra TODOS os DMCs já cadastrados (de qualquer cidade — pega também sobreposição com cidade vizinha/conurbada); "Salvar" já roda essa mesma checagem sozinho antes de gravar, só como aviso. Passe o mouse num DMC carregado pra ver nome e sigla.

Cores da rede por diâmetro

Defina uma cor fixa para cada diâmetro (DN/DE) de rede. Funciona com KMLs onde o diâmetro está identificado pelo nome da pasta (ex.: "T_50" = 50mm) — comum em exportações de DWG/Civil3D. Quando existe uma regra para o diâmetro do trecho, ela tem prioridade sobre a cor original do arquivo — não precisa mais acertar a cor manualmente antes de exportar.

Situação dos DMCs

As situações abaixo aparecem no seletor de cada DMC em Gestão. Dar uma cor a uma situação faz o contorno desse DMC usar essa cor nos MAPAS (Mapa/PC e Campo) — não muda nada no Editor de DMC, que continua com a cor automática por DMC. Uma cor personalizada definida direto num DMC específico (em Gestão) sempre tem prioridade sobre a cor da situação.

Configurações gerais

Já funciona sempre no Mapa e no Editor de DMC (desktop). Essa opção é só deste aparelho — não muda nada pros outros usuários.

Prepara a estrutura de dados para os 4 setores (SEPES/SEPEN/SEPEM/SEPEO): marca tudo que já existe como setor SEPES, separa as configurações gerais por setor e cria os 3 setores novos vazios. Rodar só UMA VEZ, com calma, antes de seguir para a Fase 2.

Lê o banco e lista o que a falha de 18/09 pode ter afetado: vazamentos substituídos, cidade SID duplicada, DMCs sem dados, telefones fictícios, tipos e serviços. Não altera nenhum dado.

Mostra a lista exata do que vai mudar e só grava depois que você confirmar. Corrige: SID duplicada, textos dos serviços 5110/5811, contadores de numeração e vazamento sem setor.
